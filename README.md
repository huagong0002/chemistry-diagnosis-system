# 化学错题智能诊断与个性化练习系统

## 项目简介

本系统是一款面向高一化学教师的智能教学辅助工具，能够：
1. 自动识别学生作业图片或文字中的化学题目和答案
2. AI智能诊断错因，生成知识薄弱图谱
3. 根据诊断结果自动生成个性化变式练习题

## 技术架构

```
┌─────────────────────────────────────────────────────────┐
│                    用户界面层 (Streamlit)                 │
├─────────────────────────────────────────────────────────┤
│  教师端: 作业上传 | 班级管理 | 诊断报告 | 练习推送         │
│  学生端: 错题查看 | 个性化练习 | 学习进度                  │
├─────────────────────────────────────────────────────────┤
│                    业务逻辑层 (Python)                    │
├────────────────┬───────────────────┬───────────────────┤
│   题目识别模块   │    错因诊断模块    │   题目生成模块     │
│   (OCR+LLM)     │   (知识图谱)      │   (提示词工程)     │
├────────────────┴───────────────────┴───────────────────┤
│                    AI服务层                             │
├─────────────────────────────────────────────────────────┤
│  通义千问 API  /  DeepSeek API  /  Ollama (本地部署)     │
├─────────────────────────────────────────────────────────┤
│                    数据存储层 (SQLite)                   │
└─────────────────────────────────────────────────────────┘
```

## 功能模块

### 1. 作业上传与识别
- 支持图片上传（拍照作业照片）
- 支持文字直接输入题目
- 自动识别题目内容和学生答案

### 2. 错因智能诊断
- 概念混淆诊断
- 计算失误分析
- 审题不清分析
- 知识缺失定位

### 3. 个性化练习生成
- 根据薄弱点生成变式题
- 难度递进式练习
- 即时反馈与解析

### 4. 教师管理后台
- 班级学生管理
- 作业批量上传
- 诊断报告查看
- 练习推送管理

## 技术栈

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Streamlit | 低代码框架，教师可快速上手 |
| AI服务 | 通义千问 / DeepSeek | 云端API，按量计费 |
| 本地AI | Ollama + Qwen2.5 | 完全免费，需GPU支持 |
| 数据库 | SQLite | 零配置，零维护 |
| 图片识别 | OCR + LLM | 双重保障识别准确率 |
