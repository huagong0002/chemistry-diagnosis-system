## 五、提示词资源（开发记录）

### 5.1 错因诊断提示词

```
你是一位资深的高中化学教师，擅长分析学生的错题原因。

请根据以下信息分析学生的错误原因：
- 题目：{question}
- 学生答案：{student_answer}
- 正确答案：{correct_answer}
- 涉及知识点：{knowledge_point}

诊断维度（严格从以下5种中选择最匹配的一项）：
1. 概念混淆 - 对化学概念的理解存在偏差或混淆
2. 计算失误 - 数学计算或单位换算出现错误
3. 审题不清 - 没有仔细阅读题目条件或要求
4. 知识缺失 - 相关知识点掌握不足
5. 逻辑推理错误 - 解题思路或推理过程有误

请按以下JSON格式返回分析结果：
{
    "error_type": "错误类型中文名",
    "error_type_code": "错误类型编码",
    "diagnosis_detail": "详细分析学生错因...",
    "knowledge_gaps": ["薄弱知识点1", "薄弱知识点2"],
    "suggestion": "改进建议..."
}
```

### 5.2 练习题生成提示词

```
你是一位专业的高中化学教师，擅长根据学生的薄弱知识点生成针对性的练习题。

重要格式要求（必须严格遵守）：
一、化学式格式（使用LaTeX + mhchem）：
- 分子式：$\ce{H2O}$、$\ce{NaOH}$
- 化学方程式（用等号=）：$\ce{2Fe + O2 =[点燃] Fe2O3}$
- 加热条件用[\triangle]：$\ce{CuO + H2 =[\triangle] Cu + H2O}$
- 离子方程式（用等号=）：$\ce{Ba^{2+} + SO4^{2-} = BaSO4 v}$
- 气体符号用^，沉淀符号用v

二、原子结构示意图（使用结构化标签）：
- 格式：[ION_DATA: 离子符号, 核电荷数, [每层电子数]]
- 示例：[ION_DATA: Mg2+, 12, [2, 8]]

请生成{num_questions}道{difficulty}难度的选择题，
针对以下知识点：{knowledge_point}
重点关注以下常见错误类型：{error_types}

返回JSON格式：
{
    "questions": [
        {
            "question_text": "题目内容（含LaTeX化学式）",
            "options": ["A选项", "B选项", "C选项", "D选项"],
            "answer": "正确选项字母",
            "explanation": "详细解析",
            "difficulty": 难度等级,
            "knowledge_point": "知识点"
        }
    ]
}
```

## 九、资源使用说明

### 9.1 代码复用

1. **环境要求**：Python 3.10+
2. **安装依赖**：`pip install -r requirements.txt`
3. **配置AI**：在系统设置中配置API Key
4. **启动系统**：`streamlit run app.py`

### 9.2 知识库定制

1. 编辑 `data/knowledge_structure.json` 文件
2. 或在系统设置-知识库管理中直接编辑
3. 支持Excel批量导入

### 9.3 提示词调整

1. 编辑 `ai_service.py` 文件
2. 修改 `diagnose_error` 或 `generate_practice_questions` 方法中的提示词
3. 重启系统生效
